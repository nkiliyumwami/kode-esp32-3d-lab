Wiring checklist

  • GPIO25 = board pin D25 → breadboard row 11 → yellow wire a11 → a24
  • 330 Ω resistor (orange‑orange‑brown‑gold): c24 ↔ c28
  • LED anode (+, long leg) in e28; cathode (−, flat side) in e29
  • Black wire a29 → blue − rail; black wire blue − rail → a17 (board GND)

MicroPython (projects/01-blink/main.py)

from machine import Pin
from time import sleep

led = Pin(25, Pin.OUT)
while True:
    led.value(1)   # ON
    sleep(1)
    led.value(0)   # OFF
    sleep(1)

Hole positions follow the 30‑pin DOIT ESP32 DevKit V1 pinout and are checked by automated connection tests. They have not been tested on real hardware yet. Clone boards can differ, so always follow the labels printed on your own board, and ask an adult to check the wiring before plugging in USB.
